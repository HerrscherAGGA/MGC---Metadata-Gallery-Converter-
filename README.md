🖼️ MGC - Metadata Gallery Converter
MGC is a portable graphical application that requires no installation. It was created to easily view, edit, and convert metadata from .png images generated with ComfyUI, Stable Diffusion, or TensorART, into a format more compatible with Civitai.

🎯 What was it created for?
This program was born for a simple reason:
I got tired of manually copying prompts and generation parameters.
Often, images downloaded from TensorART hide metadata when uploaded to Civitai, and although Tiefsee can display them, it became a hassle to fill them out each time.

With MGC you can:
View images in a thumbnail-based gallery.

Automatically display:

Positive prompts

Negative prompts

Generation parameters

Edit or copy any of them with ease.

Save metadata to .txt files or embed them back into .png images adapted for Civitai.

🛠️ Key Features

✅ Thumbnail gallery with all images from the folder

✅ Drag & drop support and folder selection

✅ Keyboard navigation (↑ and ↓ arrows)

✅ Clear display of:

Positive prompt

Negative prompt

Generation parameters (steps, sampler, seed, model, etc.)

✅ Button to copy all metadata at once

✅ One-click conversion to Civitai-compatible format

✅ Save as .txt or .png with embedded metadata

✅ Support for multiple formats: .png, .jpg, .jpeg, .webp

✅ Warning window if metadata is missing (helpful for .jpg images)

✅ User interface in English and Spanish, with a language switch button
