🖼️ MGC - Metadata Gallery Converter
MGC (Metadata Gallery Converter) is a free and open-source graphical application designed to view, edit, and convert metadata from images generated by AI tools such as ComfyUI, Stable Diffusion, and TensorArt, into a format compatible with Civitai. It is a portable, lightweight, and intuitive tool, ideal for managing AI-generated images without requiring installation.
Developed by HerrscherAGGA. Source code available on GitHub.
🎯 Purpose
MGC simplifies the management of metadata for AI-generated images, eliminating the need to manually copy prompts and parameters. It addresses common issues, such as metadata loss when uploading images to Civitai, providing a unified interface to:

View images in a gallery with thumbnails.
Extract and edit positive prompts, negative prompts, and generation parameters.
Save metadata as .txt files or Civitai-compatible .png images.
Customize the user experience with language, color, and keyboard shortcut options.

🛠️ Key Features

Image Gallery: Browse thumbnails of images in a folder, supporting .png, .jpg, .jpeg, and .webp formats.
Intuitive Navigation: Use arrow keys (↑, ↓, ←, →) or click thumbnails to explore the gallery, with global shortcuts throughout the application.
Automatic Metadata Extraction: Displays automatically:
Positive prompt.
Negative prompt.
Generation parameters (steps, sampler, seed, model, etc.).


Metadata Editing: Add or modify prompts and parameters manually if not detected.
Metadata Export:
Save metadata to .txt files.
Embed metadata in Civitai-compatible .png images.
Copy prompts and parameters to the clipboard with a single click.


Prompt Generator: Import tags from platforms like Danbooru, with tools to clean and convert prompts.
Advanced Tools:
Customize keyboard shortcuts.
Batch export metadata to .txt.
Batch edit prompts (add prefixes/suffixes).
Adjust interface colors and transparency.
Zoom, rotate, and crop images.


Multilingual Support: Switch between English and Spanish with a button in the interface.
Built-in Help: Access basic instructions via the "❓ Help" button.

📦 Requirements and Installation
MGC is a portable application that requires no installation. To get started:

Download: Obtain the mgc_mainv2.exe executable from Civitai or clone the repository from GitHub.
Folder Structure: Ensure the assets/iconos, assets/temp_demo, and assets/CHANGELOG folders are present. You may replace the contents of assets/temp_demo, but do not delete the folder or its icon.
System Requirements:
Operating system: Windows 10 or higher (tested on Windows 11).
Supported formats: .png, .jpg, .jpeg, .webp.
No additional dependencies required.




Note: If no image folder is selected, MGC defaults to assets/temp_demo.

💻 How to Use MGC

Open Folder:
Click "Open Folder" to load a directory containing images (.png, .jpg, .jpeg, .webp).


Navigate the Gallery:
Use arrow keys or click thumbnails to select an image.


View Metadata:
Prompts and parameters are displayed automatically in the metadata tab.


Edit Metadata:
If no metadata is detected, use manual fields to add prompts and parameters.


Copy or Save Metadata:
Copy All: Copy prompts and parameters to the clipboard.
Save as .txt: Export metadata to a text file.
Save as .png: Embed metadata in a Civitai-compatible image.


Prompt Generator:
Import tags from platforms like Danbooru and use cleaning and conversion tools.


Advanced Tools:
Access options like custom shortcuts, batch export, batch prompt editing, zoom, rotation, or cropping from the "Other Advanced Tools" menu.


Help:
Click the "❓ Help" button for basic in-app instructions.



Usage Example

Load a folder with images generated by Stable Diffusion.
Select an image to view its prompts and parameters.
Edit the positive prompt to add a specific description.
Save the metadata as .txt or embed it in a new .png for uploading to Civitai.
